# Spandana | Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and vanilla JavaScript. There are no build steps, package installs, or backend requirements.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any static web server. The site works as a local file; a server is optional.

## Deploy to GitHub Pages

1. Push this project to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch to publish and the `/ (root)` folder, then save.
5. Open the Pages URL shown in the repository settings after deployment completes.

The site can also be deployed to Netlify by publishing this folder as a static site; no build command is needed.
